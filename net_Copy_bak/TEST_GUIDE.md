## 一、测试前准备

### 1.1 文件清单确认

```
网络拷贝/
├── main.py              # 程序入口
├── ui.py                # GUI 布局
├── control.py           # 业务逻辑控制器
├── nic_scanner.py       # 网卡扫描模块
├── ip_config.py         # IP 配置模块
├── disk_scanner.py      # 磁盘扫描模块
├── file_transfer.py     # 文件传输模块 (HTTP Server/Client)
├── verifier.py          # CSV 校验模块
├── task                 # 需求文档 + 技术分析
└── TEST_GUIDE.md        # 本文件
```

### 1.2 硬件准备

| 设备 | 角色 | 最低要求 |
|------|------|----------|
| **设备 A** | 源设备 | 含 D/E/F 分区，有数据；网卡可用 |
| **设备 B** | 目标设备 | 磁盘容量 ≥ 源设备；网卡可用 |
| **网线** | 直连 | 千兆网线 (或通过交换机) |

### 1.3 预置测试数据 (源设备)

在源设备的正常系统下，确保 `F:\Appl\` 下有日期文件夹和 CSV：

```
F:\Appl\
  └── 2024\
      └── 06\
          └── 15\
              └── FullFilelist_DEF.csv
```

**CSV 格式要求** (UTF-8 with BOM):

| A | B (FullPath) | C | D | E (VerifyResult) |
|---|-------------|---|---|-------------------|
| 1 | D:\folder\file1.txt | | | |
| 2 | D:\folder\file2.dat | | | |
| 3 | E:\data\image.png | | | |
| 4 | F:\docs\doc.pdf | | | |

> B 列必须是 `FullPath`，E 列将填入 `Y` 或 `N`

## 五、已知限制与注意事项

1. **PE 盘符映射依赖人工** — 需用户手动识别 PE 下哪个盘对应正常系统的 D/E/F
2. **传输无断点续传** — 中断后需重新开始
3. **HTTP 单线程** — 大文件(>10GB)传输效率有限，但不影响正确性
4. **端口硬编码** — 传输端口固定 `9999`，确保不被防火墙拦截
5. **仅校验存在性** — 当前版本验证文件存在+大小非零，如需 MD5 校验可扩展
6. **嵌入式 Python** — 确保 `python.exe` 和所有 `.py` 文件在同一目录
