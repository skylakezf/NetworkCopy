# 2026-08-26

## 移除网卡手动选择 + 修复发送端开始传输按钮一直被禁用

### 背景
- 网卡在 2026-08-02 已改为全自动（发送端 bind 0.0.0.0，接收端 DHCP 全网卡广播），但 UI 仍保留"高级选项→手动选择网卡"下拉框，且 `_check_button_state` 和步骤 1 `go_step` 仍依赖下拉框值判断按钮状态 → 无网卡/扫描未完成时发送端"开始传输"按钮永远 disabled。

### 修改内容
**ui.py**
- `go_step` 步骤 1：移除 nic_ok 判断，选完角色即启用下一步
- 高级选项面板：删除"手动选择网卡"标题、"网卡优先级"提示、`tk_select_box_mqfzkd6x` 下拉框、`tk_label_nic_detail` 标签（保留自动网卡检测卡片 `tk_label_auto_nic_detail` 与折叠面板）

**control.py**
- `_populate_nics`：只做自动选择 + 更新自动网卡卡片 + 步骤1启用下一步，不再填充下拉框
- `_auto_select_wired_nic`：移除下拉框同步
- 删除 `_on_nic_selected`、`_get_adapter_desc`、`_manual_nic` 字段
- `_on_device_type_selected`：网络预配置改用 `_get_adapter_desc_from_auto()`
- `_check_button_state`：**移除 nic_selected 依赖**（核心修复），条件改为 dev_type 已选 + step>=3 + 未传输中
- `_on_prev_step` new_step==1：直接启用下一步
- `_on_dhcp_button` / `_start_source_server(manual_ip)`：直接用自动网卡
