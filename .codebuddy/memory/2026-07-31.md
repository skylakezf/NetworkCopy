## 2026-07-31 第三轮修复：全面 UI 逻辑与时序问题排查

### 1. `set_button_next("disabled")` 会隐藏按钮导致后续无法恢复
- 根因：`set_button_next("disabled")` 调用 `pack_forget()` 隐藏按钮，但 `_on_role_selected`/`_on_nic_selected`/`_on_disk_selected` 用 `config(state="normal")` 仅启用不重新 pack，导致"下一步"按钮永久消失
- 修复：`set_button_next("disabled")` 不再调用 `pack_forget()`，仅 `configure(state=DISABLED)`。按钮始终可见，禁用时灰色

### 2. 统一使用 `set_button_next()` 而非 `config(state=...)`
- `_on_role_selected`、`_on_nic_selected`、`_on_disk_selected`、`_on_next_step`、`_on_prev_step` 中所有 `tk_button_next.config(state=...)` 统一改为 `set_button_next(...)`

### 3. `_on_start_button` 先切页后校验导致用户卡在传输页
- 根因：`go_step(4)` 在校验前调用，校验失败时用户已停在步骤 4 传输页却无反应
- 修复：先做分区映射/网卡校验，通过后才 `go_step(4)` 启动传输

### 4. 步骤 3 "下一步"按钮仍启用
- 根因：步骤 3 (连接页面) 用户应点"开始传输"而非"下一步"，但"下一步"仍处于启用状态，误点会跳到步骤 4 但未启动传输
- 修复：`_on_next_step` 和 `_on_prev_step` 在 `new_step == 3` 时 `set_button_next("disabled")`

### 5. `_check_button_state` 未检查传输状态
- 根因：传输进行中从步骤 4 退回步骤 3 时，`_check_button_state` 会重新启用"开始传输"按钮
- 修复：增加 `not self._transferring` 条件，传输中不启用

### 6. `_on_transfer_failed` DHCP 按钮文本不一致
- 原代码设为 "开启DHCP"，但 UI 中原始文本是 "寻找旧电脑"
- 修复：改为 "寻找旧电脑"

### 7. `clear_log` 第二次设错状态
- 第二次 `configure(state=NORMAL)` 应为 `DISABLED`（虽未调用，仍修正）

## 2026-07-31 第四轮修复：PyInstaller 打包 bootstrap.ttf 解压失败

### 问题
- 运行 exe 时报错: `Failed to extract ttkbootstrap\assets\icons\bootstrap.ttf: decompression resulted in return code -1!`
- 根因: PyInstaller `--onefile` 模式下 UPX 压缩 exe 二进制后，运行时自解压 CArchive 中的 `bootstrap.ttf` (457KB TTF 字体) 解压失败

### 修复
- `build.ps1` PyInstaller 参数增加 `--noupx` 禁用 UPX 压缩
- 删除旧 `.spec` 文件让 PyInstaller 用新参数重新生成 (spec 中 `upx=False`)
- 构建脚本不再删除 `.spec` 文件（由 PyInstaller 自动管理）

### 验证
- 构建成功: `dist/磁盘拷贝工具.exe` 22.2MB
- 字体文件完好: TTF header `0x00010000`, 457KB
- 若 `--noupx` 仍无法解决，备选方案: `--onedir` 替代 `--onefile`（无压缩）

## 2026-07-31 第七轮修复：磁盘自动选中未启用下一步 + 分区映射折叠 + DHCP 加速

### 磁盘自动选中后仍需点击才能下一步
- 根因: `_on_next_step` 进入步骤 2 时无条件 `set_button_next("disabled")`，即使磁盘已由后台线程自动选中
- 修复: 进入步骤 2 时检查 `tk_select_box_mqfzmzbe.get()`，若磁盘已选中则直接 `set_button_next("normal")`

### 分区盘符映射改为可折叠高级选项
- 在磁盘选择后增加 `ttk.Checkbutton` "分区盘符映射 (高级)" (默认未勾选)
- 分区映射 (D> E> F>) 所有内容包裹在 `_partition_map_frame` 中，默认隐藏
- `_toggle_partition_map()`: 勾选时 `pack(after=checkbox)`，取消时 `pack_forget()`
- 减少页面杂乱，普通用户无需关注盘符映射

### DHCP IP 获取加速 (单网卡 API)
- 根因: `ipconfig /release` 和 `ipconfig /renew` 对所有网卡逐个操作，虚拟机/WiFi/VPN 等网卡逐个超时导致 30+ 秒延迟
- 修复: nic_scanner.py 新增三个函数:
  - `IP_ADAPTER_INDEX_MAP` 结构体
  - `get_adapter_index(adapter_desc)` - 按描述查找网卡 ifIndex
  - `release_dhcp_ip(adapter_index)` - 调用 IpReleaseAddress 仅释放目标网卡
  - `renew_dhcp_ip(adapter_index)` - 调用 IpRenewAddress 仅续租目标网卡
- `_setup_source_network` 改用以上 API：获取目标网卡索引 → release → 后台 renew → 轮询 IP (0.3s 间隔)
- 从 30+ 秒降至通常 3~5 秒
