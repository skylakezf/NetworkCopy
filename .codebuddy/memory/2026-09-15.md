# 2026-09-15

## 修复：网络中断 / 验证码错误提示逻辑错乱（control.py + ui.py）
- 现象：发送端网络中断时，传输页**上方红色横幅仍显示"请在新设备上输入此验证码连接"**，下方却显示"与接收端的连接已中断"；且状态行被 `show_transfer_error` 覆盖成"请返回修改验证码"，与错误区文案自相矛盾。
- 改动：
  1. `control.py` 顶部新增文案常量：`NET_LOST_TITLE/NET_LOST_MSG_SRC/NET_LOST_MSG_TGT`、`AUTH_FAIL_TITLE/AUTH_FAIL_MSG_SRC/AUTH_FAIL_MSG_TGT`、`TRANSFER_INCOMPLETE_TITLE/MSG`；文案统一为"检查网线 → 点左下角「< 上一步」返回 → 重新点开始传输/开始接收"（传输页的开始按钮是隐藏的，不能提示点它）。
  2. `ui.py: show_transfer_error(message, status_text=None)` 新增状态行文案参数（默认仍为"请返回修改验证码"）；调用方统一在 `show_transfer_error` **之后**再 `_set_status`。
  3. `_source_mark_interrupted` 增加 `ui.hide_auth_code()` 隐藏验证码横幅；`ui._auth_code_visible` 标记防止 `go_step(3)` 重新 pack 出已隐藏的横幅。
  4. `_source_mark_interrupted` 补充 `_transferring = False` + `after_cancel(_source_done_after)`，否则用户按提示返回后点"开始传输"会被"传输正在进行中"拦下（提示与实际可执行操作不一致）。
  5. 接收端 `_on_network_lost_ui`、`_on_download_complete`（网络断开分支 / 传输中途失败分支）、验证码错误分支文案同步换新。
- 已 `py_compile` 通过；未做真机联调。
