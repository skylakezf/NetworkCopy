## 操作指南 PPT + note.md 编写
- 任务：面向 0 IT 基础用户，编写软件操作指南 PPT，总结程序"会自动跳过的文件"与"工作模式"。
- 严格参考源码（file_transfer.py / control.py / config_transfer.py / disk_scanner.py / ui.py）整理 note.md，未做功能改动。
- 关键事实（来自代码）：
  - 跳过规则是**递归**的（所有层级），非仅根目录。SKIP_DIRS={AppData, System Volume Information, WeChat Files, Application Data}；SKIP_PREFIXES=("$")；SKIP_FILE_SUFFIXES=(.tmp,.log)；SKIP_FILENAMES={ntuser.dat}；SKIP_FILE_CONTAINS=(.dat.log)；SKIP_FILE_PREFIXES=("~$")；根目录 SKIP_FILES={pagefile.sys,hiberfil.sys,swapfile.sys,DumpStack.log.tmp}。
  - 根目录还跳过 Program Files / Program Files (x86) / ProgramData；Users 下只搬当前用户。
  - D 盘双分区模式：只搬当前用户 User/ + 保留 D 盘根目录非 User/ 内容。
  - 总步骤 7 步；发送端自动跳过第 5 步（导入配置仅接收端可见）。
- 交付物：
  - `note.md`（项目根目录，操作指南底稿）
  - `磁盘网络拷贝工具-操作指南.pptx`（项目根目录，16 页，pptxgenjs 生成后**套用模板.pptx 主题/母版/布局**；构建脚本 `ppt_build/build.js`，套用脚本 `ppt_build/apply_template.py`）
- 套用模板做法：用 Python 解压生成文件，把 `模板.pptx` 的 `ppt/theme/theme1.xml`、`ppt/slideMasters/slideMaster1.xml`+rels、`ppt/slideLayouts/slideLayout1-12.xml`（全部 12 个布局 + 其 _rels）、`ppt/media/image1.png` 覆盖/补写进生成文件。pptxgenjs 只生成 1 个 master/1 个 layout/1 个 theme 且 slide 都引用 slideLayout1.xml。
- ⚠️ **重要坑（已修复）**：模板母版 `_rels/slideMaster1.xml.rels` 引用了 slideLayout2–12.xml 共 11 个布局 + image1.png。若只复制 slideLayout1.xml 和母版，PowerPoint 会因找不到 slideLayout2-12.xml 报"文件损坏/无法打开"。必须**把模板全部 12 个布局 + 图片一起补进生成文件**才完整（已加 `layout_parts` 和 `media` 的追加写入逻辑）。验证脚本 `ppt_build/verify2.py` 检查所有 rels 引用完整性（broken rels targets 应为 0）。
- 模板配色：dk1=44546A、accent1=5B9BD5、accent2=ED7D31(橙)、accent4=FFC000、accent6=4472C4、accent7=70AD47；EA 字体 宋体。
- 用户要求 PPT 必须**引导界面操作（如何点下一步）**，已新增：准备3件事、第1步选角色、发送端步骤1选网卡+导出配置、步骤2-3扫描勾选、步骤4开始传输、接收端步骤1-4自动接收、步骤5导入配置、步骤6校验、步骤7完成、总流程图、常见问题。
- pptxgenjs 注意：形状常量用 `pptx.ShapeType.rect/roundRect/ellipse`；多行带 options 的 addText 必须传数组 `[{text,options}]`。
- **用户指正（重要）**：不要手绘仿真界面图！应该用**真实软件**截图。方法：用嵌入式 Python `python-3.13.14-embed-amd64\python.exe` 运行，复用 `_test_ui_full.py` 的 fixture 思路——`WinGUI()` + `Controller()` 实例化真实窗口，导航到各步骤后用 `PIL.ImageGrab.grab((rootx,rooty,rootx+w,rooty+h))` 截真实窗口。注意：`ppt_build/` 下不得有与标准库同名的文件（如 inspect.py 会屏蔽真实 inspect 导致 ttkbootstrap 导入失败）。
- **真实截图脚本**：`ppt_build/capture_all.py`（生成 11 张 1300×700 真实界面图到 `shots/`，并把各按钮相对坐标存 `coords.json`），`capture_fix.py`（补角色卡片/导出/导入按钮坐标）。关键控件真实属性名：`tk_btn_source/tk_btn_target`(角色按钮)、`tk_button_export_config`(导出)、`tk_select_box_mqfzkd6x`(网卡下拉)、`tk_select_box_mqfzmzbe`(磁盘下拉)、`tk_button_next`(下一步,x≈1138,y≈629)、`tk_button_mqfzl35t`(开始传输,x≈1128)、`tk_button_import_config`/`tk_button_skip_import`(导入/跳过)、`tk_button_use_config`/`tk_button_skip_config`(用配置/跳过配置)、`tk_button_verify`(开始校验)、`tk_progress_bar`(进度条)、`tk_text_verify_log`(校验日志)、`app.log()`(传输日志)。
- **标注脚本**：`ppt_build/annotate.py` 读 `coords.json`，在真实截图上画红色高亮框(py=red,width=4)+红标签("① 点这里")，输出到 `annotated/`。
- **最终 PPT**：`ppt_build/build.js` 用 `annotated/` 图生成 25 页 PPT（封面 + 角色选择 + 发送端4步 + 接收端6步 + 注意事项2页 + 软件不拷贝什么 + 结尾），每页图片+右侧"这一步你要做"文字，再 `apply_template.py` 套模板。中文在文件里是 UTF-8 正常（控制台 GBK 显示乱码是假象）。
