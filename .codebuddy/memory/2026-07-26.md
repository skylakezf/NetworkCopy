# 2026-07-26

## 修复 MBR 分区自动映射失败 (disk_scanner.py)

- **现象**: 选 GPT 磁盘时 D/E/F 能自动映射，选 MBR 磁盘时 `_auto_fill_drive_mapping` 收不到盘符，自动映射为空
- **根因**: `disk_scanner.py` 解析 `PARTITION_INFORMATION_EX` 的 MBR 分区类型时，偏移量写错
  - GPT 分支正确：从 union 偏移 0 读取 16 字节 PartitionType GUID (`raw[gpt_off:gpt_off+16]`)
  - MBR 分支错误：从 union 偏移 `+4` 读取 `raw[mbr_off + 4]`，但 `PARTITION_INFORMATION_MBR.PartitionType` 位于 union 偏移 **0**，`+4` 实际是 `HiddenSectors` 低字节，几乎不可能是 `0x07`，导致 MBR 的 NTFS 分区永远检测不到
  - 这同时影响两个函数：`get_partition_count()`（MBR 分区数被判成 0）和 `get_partition_drive_mapping()`（返回的 partition_map 为空）
- **修复**: 两处 MBR 分支统一改为 `raw[off + 32]`（union 起始偏移 0）读取 `PartitionType`，与 GPT 的 GUID 偏移保持一致
- 注意 `PARTITION_INFORMATION_EX` 布局: 每条分区记录 144 字节 (48 头部 + 32 对齐 + 112 union); union 在 `off+32` 开始，MBR 的 PartitionType 和 GPT 的 PartitionType GUID 都在该 union 的偏移 0
