## 跳过 .dat/.dat.log* 文件 + 接收端下载强制 3 次重试 (2026-08-04)

### 跳过 NTUSER.DAT 及其事务日志
- `SKIP_FILE_SUFFIXES` 新增 `.dat`, `.log`（原先只有 `.tmp`）
- 新增 `SKIP_FILE_CONTAINS = (".dat.log",)` 匹配 `NTUSER.DAT.LOG1`/`LOG2` 等事务日志
- 这些文件在 PE 环境中无写入权限（被 Windows 锁定），必须跳过
- 过滤逻辑: `endswith(SKIP_FILE_SUFFIXES)` + `any(pat in fname_lower for pat in SKIP_FILE_CONTAINS)`

### 接收端无法拷贝文件时强制 3 次重试再跳过
**根因**: `_download_single_file` 对非连接错误（磁盘满、权限拒绝、写入失败等）只记日志不抛异常，
`_download_single_file_with_retry` 只对连接错误重试，非连接错误直接 break。

**修复 (file_transfer.py)**, 4 处改动:
1. `_download_single_file`: 非连接异常 `except Exception` 分支加 `raise`
2. `_download_single_file_with_retry`: 对非连接异常也重试（固定 1s 后退），最多 3 次
3. `_download_batch`: 非连接异常 `except Exception` 分支加 `raise`
4. `_download_batch_with_retry`: 对非连接异常也重试（固定 1s 后退），最多 3 次

### 持久化跳过列表 (_netcopy_skiplist.json)
解决"用户发现文件没迁移，重试后同样文件还是失败"的死循环。

**新增**: `file_transfer.py` 常量区后加入:
- `_persistent_skip_list` 模块级 dict: `{normal_partition: {rel_path: reason}}`
- `_load_skip_list(drive_letters)`: 从目标磁盘加载已有跳过列表
- `_save_skip_list()`: 写入目标磁盘 JSON
- `_add_to_skip_list(partition, rel_path, reason)`: 线程安全添加
- `_is_file_skipped(partition, rel_path)`: 查询

**集成点**:
- `download_files()` 入口: 加载跳过列表 → 过滤 `all_download_tasks`（被跳过的文件不计入 total）
- `_download_single_file_with_retry` 重试耗尽: 调用 `_add_to_skip_list`
- `download_files()` 出口: 保存跳过列表并打印摘要

**效果**: 所有经过 3 次重试仍失败的文件被永久记录。下次传输自动跳过，不再浪费用户时间。

## 校验器增强: systemconfig.ini 联动 + 文件类型 G 列 (2026-08-04)

### systemconfig.ini 自动定位 CSV
- 新增 `verifier._find_csv_from_ini(f_drive_pe)`: 读取 `systemconfig.ini` 中的 `LastExportPath=` / `PATH=`
- 将原始盘符(F:)映射为 PE 盘符后查找 `FullFilelist_DEF.csv`
- `run_verification` 中 CSV 定位优先级: 手动指定 → systemconfig.ini → 最新 Appl 文件夹

### 文件类型 G 列 (fileinfo.com 集成)
**目标**: 校验结果 CSV 的 G 列写入文件类型描述, 帮助用户判断缺失文件重要性
(如 `.tmp` → "Temporary File" 不重要, `.docx` → "Microsoft Word Document" 重要)

**实现** (`verifier.py`):
- `_BUILTIN_EXTENSIONS` dict: ~120 种常见 Windows 扩展名内置映射, 即时返回
- `_fetch_extension_info(ext)`: 线程安全查询, 优先内置映射 → 模块缓存 → HTTP 查询 fileinfo.com
- HTTP 查询解析 JSON-LD 的 `alternateName` 字段 (最可靠的结构化数据来源)
- `add_file_type_column(csv_path, log)`: 收集唯一扩展名 → 内置即时 + 未知并行 (8线程) → 写入 G 列
- `run_verification` 末尾自动调用, 支持中止检查

**CSV 列结构**: A(Drive) B(FullPath) C(FileName) D(SizeBytes) E(VerifyResult) F(空) G(FileType)
