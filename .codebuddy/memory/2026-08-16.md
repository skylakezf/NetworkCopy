## 二次校验只校验缺失文件（verifier.py）
- 用户反馈：二次校验不应全量重扫 18504 文件，只校验重试下载的缺失文件
- `_retry_missing_files`/`_retry_missing_files_inner` 新增可选参数 `missing_indices_out`（list），收集缺失文件在 CSV 数据行中的索引；内层循环改用显式 `data_idx` 计数（仅 B 列非空行占索引），保证与 `verify_csv` 的 rows 索引严格一致
- `verify_csv` 新增可选参数 `target_indices`（set）：非 None 时只校验指定索引行，其余行保留原值直接写回（result_map 预填），统计/进度/日志用 work_total；返回 total 改为 work_total
- `run_verification` 二次校验：`missing_indices_out=[]` → `_retry_missing_files(...)` → `verify_csv(target_indices=set(missing_indices_out))`；合并统计保持全量视角：`passed = passed + passed2; failed = failed2`（skipped/total 不变）
- 注意：本文件函数参数刻意不写类型注解（`missing_indices_out=None` 而非 `: list = None`），避免 basedpyright 裸泛型报错，与项目风格一致

## 接收方配置导入/校验关闭增强（control.py）
- 需求：
  1) 传输完成发现配置文件点"使用此配置"→ 直接自动导入（不需再点"导入配置"）
  2) 导入配置页面，导入完成后自动跳转校验页
  3) 用户完成配置导入后禁用"跳过"按钮
  4) 校验页用户直接关闭程序（未完成/未做校验）→ 参照跳过校验发送跳过信息
- 实现：
  - `_on_use_detected_config`：`go_step(5)` 后设 `_auto_import_active=True` + `self.ui.after(150, self._on_import_config)` 自动导入（150ms 后读取已选中的配置路径）
  - `_on_import_done(success=True)`：设 `_config_import_done=True`、禁用 `tk_button_skip_import`、`after(300, go_step, 6)` 自动跳转校验页；失败则跳过按钮恢复 normal
  - `_on_skip_import`：若 `_config_import_done` 则阻止（兜底防护）
  - `shutdown()` 开头调 `_send_skip_verify_on_close()`：接收方 + `_step==6` + 未完成校验（`_verify_done=False`）且未发送过（`_send_skip_verify_done`）时，同步创建空 Unverifi 包并上传（阻塞等待，确保 os._exit 前完成）
  - `__init__` 新增 `_auto_import_active`/`_config_import_done`/`_send_skip_verify_done`
- 新增测试 C2b（导入成功自动跳 step6+禁用跳过+跳过防护）、C2c（导入失败不跳转+跳过可用）
- 注意：`after(150)` 自动导入在测试 `update_idletasks` 中不触发（timer 回调需 update()），测试安全；真实导入会改注册表等
